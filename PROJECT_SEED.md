\# Project Anchor: Arcane Culinary Archives



\## Premise

An alternate-history "pseudo-fiction" archive documenting the suppressed history of fast food. Each entry features anachronistic modern dishes (burgers, tacos, sushi, pasta) presented as genuine historical, religious, or classical artifacts.



\## The Dual-Dimension Concept

\- \*\*The Light History:\*\* Authentic period art styles (Renaissance fresco, 18th-century French engraving, Ukiyo-e woodblock, Folk quilt, Cubism, Medieval manuscript, Boschian surrealism).

\- \*\*The Dark Mirror:\*\* High-contrast Scandinavian black metal aesthetic—the same scenes recast with stark, monochrome corpse paint across all human, divine, and animal figures.



\## Data Schema for New Artifacts

When drafting new entries, output JSON matching this structure:



{

&#x20; id: "SPECIMEN-XX",

&#x20; title: "Title Here",

&#x20; era: "divine | colonial | absurd",

&#x20; date: "Era / Year",

&#x20; style: "Art Style Description",

&#x20; lightImg: "specimen-XX-light.jpg",

&#x20; darkImg: "specimen-XX-dark.jpg",

&#x20; classification: "CLASSIFICATION CODE",

&#x20; branch: "Timeline Branch Name",

&#x20; text: "Light-dimension satirical lore.",

&#x20; darkText: "Dark-mirror occult or grim Scandinavian lore."

}
